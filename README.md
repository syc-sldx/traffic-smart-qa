# 交通智问 · 独立部署版

本版本可部署到 Render 或提供 Node.js 24 的云主机，不依赖 chatgpt.site 的访问入口。源码仓库为 https://github.com/syc-sldx/traffic-smart-qa 。源码上传不等于网站上线；需要在 Render 完成部署后才能取得和测试新网址。

保留公开网页、年度数据、历史客流、知识检索、地图服务和模型分析。数据直接取自已发布云端版本的快照与年度整理文件，包含 167 条年度数值及其原单位、来源与核验标签。不会把年度汇总混作每日观测。旧平台的私人报告及用户身份不随迁移复制。

界面采用浅色侧栏、紧凑输入工具栏和清晰的回答区。定位、语音与出行设置从输入区直接打开，权限与使用说明收在“使用说明”内。出行设置按需展开，成功查询后自动收起；失败时保留条件以便修改。展开复杂表单时取消输入区吸底，避免遮挡手机上的回答。新版布局样式位于 `public/workspace.css`，构建后随公开界面一起缓存；已安装的1.1.0版APK打开网站更新即可使用，无需更换安装包。

## 运行

需要 Node.js 24。安装与构建：

```sh
npm ci --include=dev
npm run build
npm test
npm start
```

默认监听 `0.0.0.0:10000`，使用 `PORT` 指定端口。`GET /healthz` 是健康检查。分发包已包含编译后的 `runtime.mjs`，直接 `node runtime.mjs` 即可运行，不需要安装运行时依赖。

## 安装为手机 / 电脑 App

可安装安卓APK的华为鸿蒙手机现在可下载 `public/downloads/traffic-smart-qa-1.1.0.apk`，网站“安装 App → 华为 / 安卓”提供下载按钮。安装包使用系统 WebView、原生识别服务和系统朗读，不依赖Google服务；需要联网，系统未提供识别服务时可使用键盘麦克风。只适用于安卓兼容的鸿蒙或Android 6.0及以上，不作为鸿蒙NEXT原生应用分发。构建、签名与后续更新说明见 `android/README.md`。

网站已提供 PWA manifest、192/512像素图标、可遮罩图标和iPhone主屏幕图标。访问 HTTPS 网站后，点右上角“安装 App”：安卓及电脑的 Chrome / Edge 可使用浏览器安装窗口或菜单；iPhone / iPad 使用 Safari 的“分享 → 添加到主屏幕”。安装需要用户在自己的设备上确认，网页不能静默安装。安装后以独立窗口运行，保留原有公开问答与地铁图功能。是否提供浏览器原生安装按钮取决于设备、浏览器和其安装条件；没有按钮时仍显示手动步骤。

离线缓存只保存公共界面、安装脚本、manifest和图标。问答、API数据、报告和URL中的提问不写入Service Worker缓存；地铁图与问答仍需联网。新版本按界面及资产内容自动生成缓存版本，打开时检查更新，用户点击“更新 App”后再刷新，避免中途打断正在输入的内容。新实例构建命令保持 `npm run build`，会把安装资产嵌入 `runtime.mjs`；不要跳过构建。图标源文件位于 `public/icons/app.svg`，可运行 `py scripts/build_app_icons.py` 重建PNG图标，无额外Python依赖。

环境变量：

| 名称 | 用途 |
| --- | --- |
| `DATABASE_PATH` | SQLite 文件路径，默认 `./data/traffic.db`；账号与历史必须放在持久化磁盘上 |
| `AUTH_ENABLED` | 默认 `false`；持久存储配置并验证后设为 `true` 开放账号 |
| `COOKIE_SECURE` | 默认 `true`，生产环境必须保持；本地 HTTP 预览才可设为 `false` |
| `PUBLIC_ORIGIN` | 账号写操作允许的来源，默认线上 HTTPS 网址 |
| `LLM_API_KEY` | 模型密钥，仅在服务端配置 |
| `LLM_BASE_URL` | 默认 `https://api.deepseek.com` |
| `LLM_MODEL` | 默认 `deepseek-flash` |
| `AMAP_API_KEY` | 高德 Web 服务密钥 |
| `TRUST_PROXY_HOPS` | 受信任的反向代理层数，默认 0；直连不要信任客户端提交的转发地址 |

支持使用 `node --env-file=.env runtime.mjs` 读取自行配置的本地环境文件。分发包不包含密钥，已有密钥不会写入 GitHub。

## 语音输入与回答朗读

输入框旁提供“语音输入”按钮，点击后才启动浏览器的普通话识别并申请麦克风权限；文字先进入输入框，可核对后手动发送。支持中间识别结果修订、保留选区外原文、停止录音、权限/网络错误提示和45秒超时；发送、清空、切到后台或手动编辑会中止识别，避免迟到结果覆盖新问题。不持续监听，也不自动发送。识别使用设备浏览器的 Web Speech API，部分浏览器可能通过其联网语音服务处理音频；本应用不接收或保存录音、不添加语音API密钥。设备、浏览器、网络或普通话支持不满足时显示系统键盘麦克风的替代提示。

每条成功回答提供“朗读回答 / 停止朗读”，使用系统可用的中文语音，长回答分段播放。朗读内容只取回答正文，不包含SQL、来源网址或查询明细；录音与朗读互斥，避免把播放声音当作新的输入。不支持朗读的浏览器会显示说明，文字问答不受影响。自动化测试使用识别器和朗读器替身验证选区、迟到回调、权限错误、取消与长文本顺序，不会启动测试电脑的麦克风。实际识别和音色仍需在用户设备上授权后验证。

## Render 发布参数

仓库根目录已提供 `render.yaml`。可通过 https://dashboard.render.com/blueprint/new?repo=https://github.com/syc-sldx/traffic-smart-qa 创建部署。它配置了新加坡区域的免费 Web Service、Node.js 24、构建与接口测试、启动命令和 `/healthz` 健康检查。模型和地图密钥在 Render 私密输入框填写，不写入仓库。

免费实例闲置后会休眠，唤醒需要等待；不提供持久化磁盘，重启后内置数据可重建，但新生成的报告会丢失。需要长期保存报告时再选择带持久化存储的部署。配置默认不信任客户端提交的转发地址；若部署平台将全部请求代理到同一个地址，需在核对其转发规则后调整 `TRUST_PROXY_HOPS`，否则访客可能共用每分钟 30 次的查询额度。

新平台是否可从用户网络访问，必须在发布后重新实测，不能仅根据部署成功认定手机已能打开。

## 访问与数据

首页和查询接口无需登录。未登录时问答历史默认保存在当前设备的浏览器存储，可在“本机记录管理”暂停保存；报告需要各自的随机访问凭证，数据库只保存凭证哈希。每个来源地址每分钟最多 30 次有效提问，超过返回 429。数据库自动执行已有迁移并初始化内置快照；重复启动不覆盖报告和已初始化的数据。

## 地铁站点与站间换乘

已对历史数据的101个城市逐一建立覆盖记录。当前公开来源可取得其中48城的独立轨道线网，包含368条线路及分支、6767个按城市线网去重的运营站点；其中也有市域、磁浮和单轨线路，不能将这些记录统一称作地铁统计口径。数据来源为高德地铁图自身使用的公开城市目录与线路数据，抓取日期、数据URL及原始响应SHA-256保存在 `server/metro-data.json`。抓取日期不等于供应商最后更新日期，不声称已逐站获得运营方实时确认。另53城标记为来源未收录，不能据此断言当地无轨道交通。

问法示例：`南京南站怎么去南京新街口站`、`南京地铁1号线有哪些站`、`上海虹桥火车站怎么去人民广场站`、`南京地铁线路图`。出行表单支持城市选择、完整站名提示、线路全部站点浏览和高德原始线网图入口；站点匹配和静态换乘不需要模型或地图API密钥。

路线问答可连续补充“地铁”“少换乘一点”“少步行一点”“改成步行”“终点改成苜蓿园站”，页面会显示当前路线。新起终点和方式以本轮输入为准；无关问题不继续沿用旧路线。公交地铁的少换乘、少步行、较快、较省钱偏好分别传给高德策略参数；静态地铁只提供少换乘参考，其他偏好仍需实时接口。查询失败可直接重试、修改出行条件，或切换地铁站间查询；后者需要两座车站，不包含定位到车站的步行段。

换乘按来源提供的同站POI标识连接，不将仅同名但不同地点的车站合并；同名歧义要求用户补充。算法先减少换乘，再减少乘坐站数，处理分支和环线，仅连接相邻且标记运营的站点。不提供实时发车、末班车、票价、出站换乘或贯通列车保证，跨城市网络不自动拼接。普通地址、驾车和步行继续使用原有高德实时规划。

更新命令：`py scripts/import_metro.py`，更新后重新构建、测试并发布。`--from-cache` 仅用于对已下载原始数据重新规范化，不更新抓取日期。原始下载文件和诊断报告位于被忽略的 `outputs/metro-source/`，不会把任何密钥写入数据集。自动化测试覆盖用户示例、真实换乘、环线、同名站、数据缺失以及原有功能。

查询“南京市地铁图”会在回答中直接显示线网图片，支持放大、缩小、适应屏幕和原尺寸查看；“南京地铁1号线图”可显示单条线路。图片根据同一份高德公开线网数据的示意坐标绘制，标注抓取日期，保留运营站点、线路颜色、换乘标记与图例；不是运营方实时公告。原始下载更新后，导入脚本会同步重建 `server/metro-map-data.json`，也可运行 `py scripts/build_metro_maps.py` 从已有缓存重建几何数据。

公开接口：`GET /api/metro/cities`、`GET /api/metro/network?city=南京`、`GET /api/metro/stations?city=南京&q=新街口`、`GET /api/metro/map.svg?city=南京`（可选 `line=1号线`）。线网图片由同一服务生成，不依赖浏览器跳转高德、第三方图片热链或地图API密钥。站间问答继续通过 `/api/chat` 处理。


## 回答日期、处理进度与取消

回答顶部标明数据类型及日期含义：年度统计展示真实结果中的年份/统计期，历史数据展示明确日期列的覆盖范围，地铁线网展示抓取日期，地图估计与路况展示本次查询时间。抓取日期不等同于运营方更新时间，查询时间不等同于供应商观测时刻；无可靠结构化日期时显示未提供，不从问题、答案文本或SQL猜日期。打开旧对话保留原日期，并标“历史回答”。新答案的 evidence 随历史保存；旧记录可由相同的纯函数补充显示标签。

查询中显示服务端实际进入的处理阶段、等待秒数与取消入口，不展示模拟百分比。取消会结束当前等待，并通知服务端中止上游请求与尚未执行的后续步骤；已完成的账号提交不会回滚。取消与超时提示不作为正常答案保存到本机历史，可手动重新查询；不会自动重发POST。重查保留原问题模式，并重新校验临时定位，不沿用旧坐标。收到完整答案后，历史列表刷新不阻塞继续提问。

`POST /api/chat` 默认仍返回JSON。客户端以 `Accept: application/x-ndjson` 请求实际阶段帧(progress)、心跳(ping)、最终结果(result)或错误(error/status)。错误与鉴权语义保留；服务端处理上限120秒，SDK默认125秒、含初始化的界面等待上限130秒。取消信号覆盖模型/地图调用、重试等待、工具步骤及写入前检查；不承诺撤销已完成的第三方处理或已提交数据。所有新增公开脚本随界面缓存，问答/API结果仍不写离线缓存。当前免费部署的账号开关保持关闭。

## 站点点选、路线卡片与常用路线

同名站会按线路显示候选按钮；站名跨城市时先选择城市。点选携带经服务端校验的站点ID，选择失效、与名称不符或跨城市时要求重新确认。修改起终点或城市会清除对应的旧选择。单站所属线路查询不生成可收藏路线。

地铁路线按上车站、线路方向、乘坐站数和换乘分段展示，途经站点可展开；静态线网不补造票价和耗时。地图接口提供的公交、步行、驾车方案显示步骤卡片，只显示实际返回的指标；明确0元与未提供票价分别处理，同段可选公交线路不当作连续换乘。最多3方案、每方案60步，长分段默认展开前6步，提供剩余步骤入口。原始回答仍供朗读，查询明细与来源保留。

路线回答下可“收藏这条路线”，侧栏“常用路线”支持搜索、重新查询、移除和恢复。收藏独立于问答历史开关，保存在当前设备，不跨设备同步；最多100条（含已移除）。仅保存城市、固定起终点、方式、偏好和必要站点ID，不缓存旧答案或设备坐标；当前位置或纯坐标须改为固定站点/地址后才能收藏。打开收藏会重新请求服务，沿用当前服务数据重新规划；已有站点ID失效时重新点选。清理本站数据或卸载应用可能丢失本机收藏。

## 账号、历史与长记忆

当前免费部署关闭云端账号，提供本机历史：刷新恢复最近对话、搜索问答、重开对话、移入回收站和恢复。“本机记录管理”可暂停后续保存、显示并复制 JSON 备份，或在确认后清空本机记录。每设备最多100段对话、每段200轮，总量约150万字符；空间不足时提示本轮未保存，保留旧记录，不自动删旧。大结果保存摘要并提示。清理网站数据、卸载应用或更换设备可能丢失记录；网页与APK的存储也独立，共用设备上的其他使用者可看到记录。本机历史不跨设备同步、不自动上传完整存档；继续问答时仍会向本应用服务端发送本轮问题和最近几轮上下文。设备定位坐标、请求诊断、解析门牌地址、密码、令牌不会自动写入本机历史；主动输入的问题文本仍会保存。备份含问答内容，请保存在自己的设备上。

启用持久存储和 AUTH_ENABLED 后，使用用户名（3—32位英文、数字、下划线）和密码（10—128位）注册。密码经带随机盐的 scrypt 派生后存储；会话只存令牌摘要，HTTPS Cookie 设为 HttpOnly、Secure、SameSite=Lax。用户名登录暂不提供邮件找回，请妥善保存凭据。

启用云端账号后，新问答写入账号；手机与电脑登录同一账号，可刷新历史、打开旧对话继续问、搜索记录、移入回收站和恢复。会话在同一账号内同步，不自动把未登录时的本机问答迁入账号。切回前台时刷新当前会话，其他设备操作也可用“刷新历史记录”同步。登出只退出当前设备，不清除账号记录。

“账号与记忆”可设置常用城市、默认出行方式与偏好；也可提问“请记住我常用城市是南京”。新提问会使用本会话最近6轮、本人历史中的最多3条相关记录和所保存偏好，作为上下文。关闭历史检索后不再检索其他对话；已存偏好可编辑或清空。回收站对话不参与检索；旧交通答案只供回顾，实时信息仍需新查。此功能使用本人历史检索与偏好注入，不承诺模型能记住每条记录。

云端账号的历史数据保存在服务端数据库，浏览器只记住最后打开的账号对话编号；账号记录、密码或会话令牌不写入 localStorage。未登录的本机历史独立保存在 localStorage；Service Worker 的离线缓存仅缓存公开界面资源，不缓存历史、API响应和报告。账号导出会生成3分钟有效的私密下载链接，请勿分享该链接或导出的备份。模型请求可能含所选历史上下文和偏好，使用既有服务端模型提供方。不同账号的对话、报告与导出都按账号隔离。

`render.yaml` 仍为免费演示配置，账号默认关闭。经费用审批后，可使用 `render-memory.yaml` 以 adopt 模式更新既有 traffic-smart-qa 服务：0.5c-512mb 单实例 + 1GB 磁盘 /var/data，SQLite 写入 /var/data/traffic.db。按2026-11-11公布价格约7.25美元/月，不含模型、地图及额外流量费用。不要直接在免费临时文件系统启用账号。持久盘只支持单实例，部署时有短暂中断；升级不导入旧临时报告。新付费配置的 Blueprint autoSync 应关闭，先审阅计划再批准；未在文件中声明的现有API密钥继续保留。旧 render.yaml 不应再同步覆盖付费配置。

## 本次定位

点击“定位我的城市”后才请求设备授权。网页通过 HTTPS Geolocation，APK1.1.0 通过 Android 原生前台 LocationManager 获取单次位置；不申请后台定位，切后台停止请求。拒绝授权仍可手动填城市和起点。原始GPS坐标仅发送给本应用服务端，并由高德进行坐标转换和城市/行政区解析；不显示完整门牌地址，不自动写入账号偏好、问答历史或离线缓存。用户自己输入的问题文本仍会作为历史保存。

定位成功会填入出行城市，精度不超过1500米时可点“作为路线起点”，再填写目的地。只接受10分钟内的本次位置，不把旧历史里的“当前位置”当作现在的位置。华为近似定位可能精度不足，可重新授权精确位置或手动填写。旧APK1.0.0需下载并使用相同签名覆盖安装1.1.0，网页更新不能增加原生位置权限。构建与浏览器测试不等同于华为真机验证。
