# 交通智问 · 独立部署版

本版本可部署到 Render 或提供 Node.js 24 的云主机，不依赖 chatgpt.site 的访问入口。源码仓库为 https://github.com/syc-sldx/traffic-smart-qa 。源码上传不等于网站上线；需要在 Render 完成部署后才能取得和测试新网址。

保留公开网页、年度数据、历史客流、知识检索、地图服务和模型分析。数据直接取自已发布云端版本的快照与年度整理文件，包含 167 条年度数值及其原单位、来源与核验标签。不会把年度汇总混作每日观测。旧平台的私人报告及用户身份不随迁移复制。

## 运行

需要 Node.js 24。安装与构建：

```sh
npm ci --include=dev
npm run build
npm test
npm start
```

默认监听 `0.0.0.0:10000`，使用 `PORT` 指定端口。`GET /healthz` 是健康检查。分发包已包含编译后的 `runtime.mjs`，直接 `node runtime.mjs` 即可运行，不需要安装运行时依赖。

## 安装为手机 / 电脑 App

可安装安卓APK的华为鸿蒙手机现在可下载 `public/downloads/traffic-smart-qa-1.0.0.apk`，网站“安装 App → 华为 / 安卓”提供下载按钮。安装包使用系统 WebView、原生识别服务和系统朗读，不依赖Google服务；需要联网，系统未提供识别服务时可使用键盘麦克风。只适用于安卓兼容的鸿蒙或Android 6.0及以上，不作为鸿蒙NEXT原生应用分发。构建、签名与后续更新说明见 `android/README.md`。

网站已提供 PWA manifest、192/512像素图标、可遮罩图标和iPhone主屏幕图标。访问 HTTPS 网站后，点右上角“安装 App”：安卓及电脑的 Chrome / Edge 可使用浏览器安装窗口或菜单；iPhone / iPad 使用 Safari 的“分享 → 添加到主屏幕”。安装需要用户在自己的设备上确认，网页不能静默安装。安装后以独立窗口运行，保留原有公开问答与地铁图功能。是否提供浏览器原生安装按钮取决于设备、浏览器和其安装条件；没有按钮时仍显示手动步骤。

离线缓存只保存公共界面、安装脚本、manifest和图标。问答、API数据、报告和URL中的提问不写入Service Worker缓存；地铁图与问答仍需联网。新版本按界面及资产内容自动生成缓存版本，打开时检查更新，用户点击“更新 App”后再刷新，避免中途打断正在输入的内容。新实例构建命令保持 `npm run build`，会把安装资产嵌入 `runtime.mjs`；不要跳过构建。图标源文件位于 `public/icons/app.svg`，可运行 `py scripts/build_app_icons.py` 重建PNG图标，无额外Python依赖。

环境变量：

| 名称 | 用途 |
| --- | --- |
| `DATABASE_PATH` | SQLite 文件路径，默认 `./data/traffic.db`；需要保留报告时应放在持久化磁盘上 |
| `LLM_API_KEY` | 模型密钥，仅在服务端配置 |
| `LLM_BASE_URL` | 默认 `https://api.deepseek.com` |
| `LLM_MODEL` | 默认 `deepseek-flash` |
| `AMAP_API_KEY` | 高德 Web 服务密钥 |
| `TRUST_PROXY_HOPS` | 受信任的反向代理层数，默认 0；直连不要信任客户端提交的转发地址 |

支持使用 `node --env-file=.env runtime.mjs` 读取自行配置的本地环境文件。分发包不包含密钥，已有密钥不会写入 GitHub。

## 语音输入与回答朗读

输入框旁提供“语音输入”按钮，点击后才启动浏览器的普通话识别并申请麦克风权限；文字先进入输入框，可核对后手动发送。支持中间识别结果修订、保留选区外原文、停止录音、权限/网络错误提示和45秒超时；发送、清空、切到后台或手动编辑会中止识别，避免迟到结果覆盖新问题。不持续监听，也不自动发送。识别使用设备浏览器的 Web Speech API，部分浏览器可能通过其联网语音服务处理音频；本应用不接收或保存录音、不添加语音API密钥。设备、浏览器、网络或普通话支持不满足时显示系统键盘麦克风的替代提示。

每条成功回答提供“朗读回答 / 停止朗读”，使用系统可用的中文语音，长回答分段播放。朗读内容只取回答正文，不包含SQL、来源网址或查询明细；录音与朗读互斥，避免把播放声音当作新的输入。不支持朗读的浏览器会显示说明，文字问答不受影响。自动化测试使用识别器和朗读器替身验证选区、迟到回调、权限错误、取消与长文本顺序，不会启动测试电脑的麦克风。实际识别和音色仍需在用户设备上授权后验证。

## Render 发布参数

仓库根目录已提供 `render.yaml`。可通过 https://dashboard.render.com/blueprint/new?repo=https://github.com/syc-sldx/traffic-smart-qa 创建部署。它配置了新加坡区域的免费 Web Service、Node.js 24、构建与接口测试、启动命令和 `/healthz` 健康检查。模型和地图密钥在 Render 私密输入框填写，不写入仓库。

免费实例闲置后会休眠，唤醒需要等待；不提供持久化磁盘，重启后内置数据可重建，但新生成的报告会丢失。需要长期保存报告时再选择带持久化存储的部署。配置默认不信任客户端提交的转发地址；若部署平台将全部请求代理到同一个地址，需在核对其转发规则后调整 `TRUST_PROXY_HOPS`，否则访客可能共用每分钟 30 次的查询额度。

新平台是否可从用户网络访问，必须在发布后重新实测，不能仅根据部署成功认定手机已能打开。

## 访问与数据

首页和查询接口无需登录。对话历史保存在浏览器会话；报告需要各自的随机访问凭证，数据库只保存凭证哈希。每个来源地址每分钟最多 30 次有效提问，超过返回 429。数据库自动执行已有迁移并初始化内置快照；重复启动不覆盖报告和已初始化的数据。

## 地铁站点与站间换乘

已对历史数据的101个城市逐一建立覆盖记录。当前公开来源可取得其中48城的独立轨道线网，包含368条线路及分支、6767个按城市线网去重的运营站点；其中也有市域、磁浮和单轨线路，不能将这些记录统一称作地铁统计口径。数据来源为高德地铁图自身使用的公开城市目录与线路数据，抓取日期、数据URL及原始响应SHA-256保存在 `server/metro-data.json`。抓取日期不等于供应商最后更新日期，不声称已逐站获得运营方实时确认。另53城标记为来源未收录，不能据此断言当地无轨道交通。

问法示例：`南京南站怎么去南京新街口站`、`南京地铁1号线有哪些站`、`上海虹桥火车站怎么去人民广场站`、`南京地铁线路图`。出行表单支持城市选择、完整站名提示、线路全部站点浏览和高德原始线网图入口；站点匹配和静态换乘不需要模型或地图API密钥。

换乘按来源提供的同站POI标识连接，不将仅同名但不同地点的车站合并；同名歧义要求用户补充。算法先减少换乘，再减少乘坐站数，处理分支和环线，仅连接相邻且标记运营的站点。不提供实时发车、末班车、票价、出站换乘或贯通列车保证，跨城市网络不自动拼接。普通地址、驾车和步行继续使用原有高德实时规划。

更新命令：`py scripts/import_metro.py`，更新后重新构建、测试并发布。`--from-cache` 仅用于对已下载原始数据重新规范化，不更新抓取日期。原始下载文件和诊断报告位于被忽略的 `outputs/metro-source/`，不会把任何密钥写入数据集。自动化测试覆盖用户示例、真实换乘、环线、同名站、数据缺失以及原有功能。

查询“南京市地铁图”会在回答中直接显示线网图片，支持放大、缩小、适应屏幕和原尺寸查看；“南京地铁1号线图”可显示单条线路。图片根据同一份高德公开线网数据的示意坐标绘制，标注抓取日期，保留运营站点、线路颜色、换乘标记与图例；不是运营方实时公告。原始下载更新后，导入脚本会同步重建 `server/metro-map-data.json`，也可运行 `py scripts/build_metro_maps.py` 从已有缓存重建几何数据。

公开接口：`GET /api/metro/cities`、`GET /api/metro/network?city=南京`、`GET /api/metro/stations?city=南京&q=新街口`、`GET /api/metro/map.svg?city=南京`（可选 `line=1号线`）。线网图片由同一服务生成，不依赖浏览器跳转高德、第三方图片热链或地图API密钥。站间问答继续通过 `/api/chat` 处理。
